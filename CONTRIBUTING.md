# Contributing

**Honua Server does not accept code contributions.** It is Fair Source software
(Fair Core License, FCL-1.0-ALv2) developed and copyrighted by Honua Geo Inc. Keeping a
single copyright holder is what lets Honua Geo Inc. license the server commercially,
grant the Apache-2.0 future license on each release, and answer for the code to
customers and auditors. Pull requests from outside the organization are closed
automatically by `.github/workflows/close-external-prs.yml`.

What is welcome:

- **Bug reports and feature requests** as GitHub issues. Use the issue templates;
  include the capability key when you know it.
- **Security findings** through the process in [SECURITY.md](SECURITY.md). Do not open
  public issues for suspected vulnerabilities.
- **Interoperability reports** from client tooling (QGIS, ArcGIS, GDAL, OWSLib and
  others) as issues, with the request and response that misbehaved.
- **Questions and design feedback** on the open standards Honua implements, in the
  standards repositories: [geospatial-mcp](https://github.com/honua-io/geospatial-mcp)
  and [geospatial-grpc](https://github.com/honua-io/geospatial-grpc).

If you have a patch, describe the fix in an issue and we will implement it. If you need
a change that only you can make, fork under the terms of the LICENSE; the Permitted
Purpose covers internal use and modification.

The SDKs, Console, Studio and the open protocol standards are Apache-2.0 and have their
own contribution terms in their repositories.
