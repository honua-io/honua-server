# Metadata and Catalog Parity Matrix

This matrix is the canonical server-side inventory for metadata and catalog
reads that first-party SDKs must align to. It is tracked by
[honua-server#955](https://github.com/honua-io/honua-server/issues/955) under
the cross-repo epic
[honua-server#954](https://github.com/honua-io/honua-server/issues/954).

The machine-readable inventory is
[`metadata-catalog-endpoints.v1.json`](metadata-catalog-endpoints.v1.json).
SDK implementation slices are tracked in
[honua-sdk-dotnet#146](https://github.com/honua-io/honua-sdk-dotnet/issues/146),
[honua-sdk-js#139](https://github.com/honua-io/honua-sdk-js/issues/139), and
[honua-sdk-python#54](https://github.com/honua-io/honua-sdk-python/issues/54).
OGC API Records server implementation is tracked by
[honua-server#952](https://github.com/honua-io/honua-server/issues/952).

## Use The Right Catalog

| Surface | Use it for | Do not use it for |
|---|---|---|
| OGC API Records | Public, standards-based catalog discovery across services, layers, records, and safe metadata once #952 lands. | Admin-only metadata mutation or migration planning. |
| Honua admin catalog and metadata resources | Operator/control-plane service, layer, group, source descriptor, manifest, and style metadata. | Anonymous public discovery. |
| STAC | Spatiotemporal asset cataloging, collection/item search, and imagery/asset-oriented discovery. | General service catalog replacement. |
| Migration source inventory | External ArcGIS GeoServices REST and GeoServer REST assessment before import or cutover. | Publishing Honua's public catalog outward. |
| Protocol-native metadata | Exact service capabilities for FeatureServer, MapServer, ImageServer, OGC, WFS, WMS, WMTS, WCS, OData, and scenes. | Cross-protocol catalog normalization by itself. |

## Categories

- `public-catalog-read`: Public or policy-filtered discovery surfaces intended
  for non-admin SDK consumers.
- `admin-control-plane-metadata-read`: Admin-only metadata and catalog surfaces.
- `external-source-inventory-read`: Server-backed scanners for external source
  systems.
- `protocol-native-metadata-read`: Standards or compatibility metadata for one
  protocol family.

## SDK Alignment Rules

1. SDKs must implement all `implemented` entries that are in scope for that
   repository, or document an explicit deferral in the relevant child issue.
2. SDKs must not implement OGC Records before
   [honua-server#952](https://github.com/honua-io/honua-server/issues/952)
   pins the final route and query contract.
3. Protocol-native metadata clients must preserve raw protocol payload access.
4. Public catalog clients must apply the same auth headers, retry policy, error
   normalization, and pagination semantics as equivalent feature query clients.
5. Admin metadata clients must keep admin envelopes, ETags, precondition errors,
   and compatibility feature flags visible enough for automation.
6. Migration inventory clients must preserve stable artifact identifiers and
   compatibility codes without collapsing them into display strings.
