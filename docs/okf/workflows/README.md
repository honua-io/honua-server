# GA workflow vocabulary foundation

The vocabulary owns conversational aliases and explicit clarification choices. The grammar owns operation inputs, effects, preconditions, products, secret-reference paths, observation and identity requirements, and transport bindings. Capability maturity and edition remain owned by the existing capability registry. This extension is a proposal contract, not evidence that an executor implements it.

Run `python3 scripts/okf/generate-workflow-bundle.py` after editing either canonical JSON source. `--check` rejects stale output, undeclared alias collisions, missing clarification targets, invalid choices, duplicate operations, and missing capability joins. Core compilation runs that validation. `python3 scripts/okf/test-workflow-bundle.py` tests generator refusal cases.

The generated bundle contains the alias index, operation-derived OKF edges, and Console pathway templates. Clients must query current permissions, capabilities, edition and prerequisite state before offering a pathway. Templates exclude platform installation and publication approval; they do not claim current availability. All proposed executors are explicitly unavailable until independently qualified. Existing MCP names are descriptive bindings and remain unchanged.

`Honua.Core.Features.Workflow.WorkflowBundle.LoadDefault()` loads the embedded generated bundle. `WorkflowResolver.Resolve` accepts text, server-derived authorized term IDs, context and an optional clarification ID/choice bound by its caller to the current turn. Its output is a candidate or clarification, never authorization or execution. A declared ambiguous phrase still requires clarification when authorization leaves just one possible term. Longest phrase selection occurs before permission filtering. The caller must not accept term grants or turn identity from untrusted model input.

`source` is only a conversational alias. It does not rewrite schema properties such as `source.kind`. `publish the data/layer` asks explicitly whether the user means a one-layer service or governed content publication. `style.apply` requires an actual working-draft/shared-catalog target to classify effects. Save remains a separate server-state operation; approval requires a separate human. The grammar caps automatic validation repairs at two. This foundation does not change the existing spec parser, imperative tools, RC release pins, or executor behavior.
