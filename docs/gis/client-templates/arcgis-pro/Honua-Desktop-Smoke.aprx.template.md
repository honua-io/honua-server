# GeoServices REST certification template

Desktop project construction and execution instructions are maintained in the
private certification producer. This public template records only the protocol
surfaces that a certification bundle may cover:

- GeoServices REST FeatureServer
- GeoServices REST MapServer

For each surface, publish the certification bundle digest, applicable cell IDs,
and pass/fail disposition. Do not record the desktop product, product version,
operator procedure, project-file details, credentials, or local paths here.
