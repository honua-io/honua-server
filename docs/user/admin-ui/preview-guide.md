# Map Preview

Use the preview to validate data and styling before sharing a layer.

---

## Preview a Layer

1. Open **Preview**.
2. Select a layer.
3. Pan/zoom to validate features.

---

## What to Look For

- Geometry alignment (CRS correctness)
- Styling and symbolization
- Missing or unexpected attributes
