# Layer Publishing

Use this guide to publish PostGIS tables as layers.

---

## Publish a Layer

1. Open **Layers**.
2. Select a connection.
3. Choose a table and geometry column.
4. Set SRID and display name.
5. Publish.

---

## Common Options

- **Title/Description**: user-facing metadata.
- **Geometry type**: inferred from the table.
- **Enable/Disable**: control exposure without deleting.
