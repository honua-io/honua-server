# Map Styling

Use this guide to apply and customize styles for layers.

---

## Apply a Style

1. Open **Styles**.
2. Select a layer.
3. Choose a base style or edit JSON.
4. Save and preview.

---

## Tips

- Keep styles simple for large datasets.
- Use data-driven styling sparingly to avoid heavy client rendering.
- Validate style JSON before saving.
