# Database Connections

Use this guide to create, test, and manage PostGIS connections in the Admin UI.

---

## Create a Connection

1. Open **Connections**.
2. Select **New Connection**.
3. Provide host, database, username, and password.
4. Save.

---

## Test a Connection

- Use **Test Connection** to validate connectivity and PostGIS support.

---

## Tips

- Use a read-only user for read-only services.
- Prefer TLS in production.
- Keep credentials in a secret manager.
