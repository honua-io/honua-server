# Data Import

Use this guide to upload files and import data into Honua.

---

## Import a File

1. Open **Import**.
2. Upload your file (GeoJSON, Shapefile, GeoPackage).
3. Preview the data.
4. Confirm target layer and run the import.

---

## Monitor Imports

- Check job status in the import list.
- Review errors for failed rows or geometry issues.

---

## Tips

- Validate geometry before import.
- Split very large files into smaller batches.
- Use consistent SRID where possible.
