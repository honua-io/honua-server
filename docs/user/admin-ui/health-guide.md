# Health Monitoring

Use the Admin UI to check service health and basic operational status.

---

## What to Check

- Liveness and readiness status
- Recent errors (if enabled)
- Database connectivity indicators

---

## Next Steps

If health checks fail:
- Review logs and metrics.
- Use the troubleshooting guides in the DevOps section.
