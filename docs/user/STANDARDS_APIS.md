# Standards APIs

Honua exposes industry-standard GIS APIs for interoperability with existing clients and tools.

## Supported standards
- GeoServices REST FeatureServer (Esri-compatible)
- OGC API Features
- OGC API Tiles
- OData v4
- Vector Tiles (MVT)
