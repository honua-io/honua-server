| Publication tenant visibility omitted by protocol paths | P1 | Confirmed in discovery, search, render/tile, related-record, replication and service-wide selection paths across Records, OData, OGC Maps, WMS/WMTS, ImageServer, MapServer, VectorTileServer, PMTiles, StaticMap and FeatureServer. Existing resource/service access checks omit publication tenant scope. Filtering must precede primary selection/deduplication and cache access. OData and imagery regressions reproduce the defect; WMS/WMTS eight-case suite passes. Repairs are in draft PRs #7025, #7030 and #7031 under #6989. The finite 107-file source census is adjudicated; runtime verification and integrated review remain in progress. |
| Published forms accept writes forbidden by current field policy | P1 | Package-time editability can outlive current resource restrictions. Current schema enforcement is in draft PR #7032 for #6991; runtime verification remains pending. |
| OGC API PATCH removes protected attributes | P1 | Null-valued submitted properties can bypass field validation; unchanged protected attributes in the merged row must not be rejected as new writes. Regression and shared policy repair in draft PR #7032 for #6996. The separate `properties: null` whole-properties behavior already has a mapping and remains a control case. |
| Existing-row RLS missing from canonical writes | P1 | Forms expose batch update/delete paths without original-row visibility checks; provider batch validation checks only the resulting row, and single-feature methods bypass the check. | OIDC audience identities compared without case sensitivity | P1 | Bearer, portal and provider-narrowed validators use case-insensitive custom audience checks; an otherwise valid token for a case-distinct audience can match. | SAML local replay claim not atomic | P2 | Memory-cache factory can execute concurrently for the same assertion; Redis NX path is unaffected. | Import progress read failure skips leadership check | P2 | Monitor catches failed progress reads before reaching heartbeat. Target advisory lock mitigates duplicate writes but does not stop stale execution. Fixed in draft PR #6995 (`3d3c8813f3`); regression failed on baseline, 13 focused tests pass after correction; primary independent review complete. CI PR Gate, Build/tests, formatting, CodeQL, affected shards and runtime proofs passed. Review Gate declines draft status as expected. |
| Import replacement cascades into independent dependencies | P1 | Target ownership check does not authorize deleting dependent views/materialized views or foreign keys. | Version-job fallback loses newer state after Redis recovers | P2 | A stale existing Redis record wins over newer node-local fallback state. Tracked in #6997; remediation deferred. |
| Reconciler renewal exception leaves reconciliation running | P2 | Renewal task faults without cancelling its linked token; awaiting the fault also skips release. Submission CAS mitigates duplicate submission. Tracked in #6990; remediation deferred. |

The initial eight P1 finding families and the subsequently identified #7041 are tracked above; none is closed without verification. Another P1, #7028, has ten intended Core baseline failures and two passing controls; routed OData validation remains pending: managed resources sharing one actual storage ID can resolve the first resource’s row/field policy instead of the resource authorized by the route. The supported source path is OData's managed-binding fallback; FeatureServer's exact-bound reader is a safe control. Real-Postgres routed regressions include a noncolliding policy control and denial of the admin-only resource; the initial routed fixture stopped at an incorrect GeoServices HTTP-status assertion, now corrected to inspect the ArcGIS error envelope; that failure is not counted as OData exposure proof. The bounded candidate reuses the canonical bound reader and fails closed for ambiguous numeric operations with applicable policy. No supported P0 finding so far. Finding counts are not evidence of complete coverage.
