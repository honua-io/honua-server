# PR #1236 — Modularization (Phases 0–3 + structural-audit follow-through)

PR #1236 is the single bundled landing of the Honua server modularization
work: it consolidates Phases 0 through 3 of the modular-monolith plan
plus substantial structural-audit follow-through into one large refactor.
The change rearranges the assembly topology (extraction of
`Honua.Core.Abstractions`, `Honua.Hosting`, and `Honua.Protocols.OData`;
per-protocol test projects for 7 protocols), tightens cross-protocol
architecture invariants, and decomposes the
`Server.Features.Infrastructure` grab-bag. **#1236 is internal
restructuring only — there are no public API, wire-format, gRPC,
OpenAPI, or runtime-behaviour changes.**

The branch is `refactor/core-abstractions-phase0b-metadata-v2`. It
builds on top of the metadata v2 cutover (#1234) but does not require
any further data migration.

## Shipped slices

### Phase 0 — `Honua.Core.Abstractions`

- Scaffold the new contract assembly.
- Move the outbox contract, metadata v2 closure, filter abstractions,
  and the transitive domain closure (Console, Scene, Security,
  FeatureStore) into it.
- Move shared `SpatialReference`, `BoundingBox`, `FieldNames`,
  `CrsDefinition`, and `IDatabaseConnectionProvider`.
- Heavy-dependency invariant enforced by
  `CoreAbstractionsIsolationTests` (no Npgsql, no NetTopologySuite, no
  AWSSDK, no Parquet.Net, no FlatGeobuf in the abstractions assembly).

### Phase 1 — Plug-in host pattern

- Introduce `IHonuaProtocolModule`.
- Per-protocol modules: `ODataProtocolModule`,
  `OgcApiProtocolModule`, `OgcClassicProtocolModule`,
  `GeoServicesProtocolModule`.
- AOT-safe composition entry points
  (`AddDiscoveredProtocolModules` / `MapDiscoveredProtocolModules`).
- 9 new arch tests covering coverage and discovery.
- Stretch: physical extraction of the `Honua.Protocols.OData`
  assembly with `InternalsVisibleTo` granted to its test project.

### Phase 2 — Per-protocol test project split

- 27 OData tests → `Honua.Protocols.OData.Tests`.
- 45 OGC API tests → `Honua.Protocols.OgcApi.Tests`.
- 14 OGC Classic tests → `Honua.Protocols.OgcClassic.Tests`.
- 70 GeoServices tests → `Honua.Protocols.GeoServices.Tests`.
- Mcp / Scene / Stac protocol test projects added.
- 11 residual protocol tests relocated; 3 Residual CI shards retired.

### Phase 3 — CI rework

- Cross-job binary cache wired into `setup-dotnet-ci`.
- Affected-projects build for foundation-tests and
  warnings-as-errors / postgres-compat scoping.
- Per-shard csproj routing in the `server-tests` matrix.
- Scoped restore steps; xunit parallel config ported to OData shards.

### audit-A1 — `Server.Features.Infrastructure` decomposition

- Scaffold `Honua.Hosting`.
- Extract `Infrastructure.Models`, `Infrastructure.Caching`,
  `Authentication + Validation + Helpers`, and
  `Infrastructure.Events` (less `FeatureChangeRetryQueue` impl) into
  `Honua.Hosting`.
- Relocate `IHonuaProtocolModule` to `Honua.Hosting` post-carve.
- Grant `InternalsVisibleTo` to remaining protocol test projects.
- Relocate 38 `ControlPlane` files and 26 `Styling` files out of
  the Infrastructure grab-bag.
- Break OData back-edges in `Infrastructure.Models` and
  `Infrastructure.Validation` via delegate registration.
- Install `InfrastructureMisfileRatchetTests` and the
  no-protocol-back-edges ratchet.

### audit-A2 — `Honua.TestKit` carve

- Move `JobStoreTestExtensions` + `LocalstackCli` + remaining
  TestKit-eligible helpers from `Server.Tests` into `Honua.TestKit`.
- Undo `McpTestFactory` back-port now that consumers moved to
  `Mcp.Tests`.
- Extract Metadata v2 graph factories from `WebAppFixture` into
  TestKit mixins (audit-A2 first slice).

### audit-B1 — Cross-protocol isolation

- Tighten the cross-protocol isolation allow-list with a file-count
  ratchet.

### audit-C1 — Throwing default-interface-method ratchet

- Promote 12 throwing default-interface-methods on v2 contracts to
  `abstract`.

### audit-C2 — `Features/Import` god-folder split

- Split `Features/Import` (208 files) into
  `Migration` / `FileImport` / `RasterImport` across `Honua.Core`,
  `Honua.Postgres`, `Honua.Server`.
- Route Migration / FileImport / RasterImport through dedicated CI
  shards.
- Fix `IArcGisMigrationEvidenceStore` cref post-move.

### audit-C3 — `IDatabaseSession` / `IDatabaseSessionFactory`

- Introduce `IDatabaseSession` and `IDatabaseSessionFactory` (the
  narrowed replacement for the leaky
  `IDatabaseConnectionProvider`).
- Add the shared `AdoNetDatabaseSession` implementation plus
  MySql / DuckDB sessions.
- Coexists with the legacy provider per ADR-0046.

### audit-C4 — `ISqlDialect`

- Define `ISqlDialect` and the shared expression-visitor base.
- Add per-provider `ISqlDialect` implementations.
- Migrate Postgres and MySql translators onto the shared base.
- Ship architecture guardrail + dialect unit tests.

### audit-D1 / D2 / D4

- D1: fold `DataProviderNames.Normalize` into its two branching
  sites.
- D2: record ADR-0045 deferring colliding migration-prefix
  renumbering.
- D4: drop 6 v1 metadata-graph tables orphaned by the v2 cutover.

### `PostgreSqlLayerPublishingService` split

- Pure file split of the 2,777-LOC service into six partials
  (`MetadataV2Graph`, `Validation`, `LayerPersistence`, ...). No
  behaviour change.

### ADRs landed

- ADR-0041 — Phase 1 plug-in host extension to the
  `Honua.Core.Abstractions` extraction.
- ADR-0042 — Per-protocol test project split.
- ADR-0043 — Modularization CI rework.
- ADR-0044 — `Server.Features.Infrastructure` decomposition.
- ADR-0045 — Defer renumbering of colliding migration sequence
  numbers.
- ADR-0046 — Progressive `IDatabaseSession` migration with
  coexistence.

## What did not change

- No public API surface changes.
- No gRPC / OpenAPI / OData / OGC wire-format changes.
- No runtime behaviour changes.
- No database migrations beyond the 6 orphaned v1 tables dropped in
  audit-D4 (post-cutover cleanup of unreferenced tables — no live
  data path depends on them).
- No environment variable, secret, or infrastructure changes.

Internal namespace moves
(`Honua.Core` → `Honua.Core.Abstractions` for migrated contract
types; `Server.Features.Infrastructure.*` → `Honua.Hosting` for
extracted hosting infrastructure; `Features/Import` →
`Features/Migration · FileImport · RasterImport`) are internal-only
and consumers were updated in the same commits.
