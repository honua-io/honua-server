GeoServices REST

Esri FeatureServer + MapServer

  • 23 FeatureServer operations (query, edits, attachments, related records, replicas, domains, statistics)
  • 8 MapServer operations (export, identify, find, legend, query, tiles)
  • Full query parameter support (spatial, temporal, statistics, pagination, sorting)
  • Batch edits via applyEdits and append

Existing ArcGIS Pro, ArcGIS JS, and Esri SDK apps connect without code changes.

OGC API

Features, Tiles, Maps, WMS, WMTS

  • OGC API Features with CQL2 filtering (10 spatial, 14 temporal, 4 array predicates, 32+ functions)
  • OGC API Tiles with MVT and raster output
  • OGC API Maps for dynamic rendering
  • WMS 1.3 and WMTS 1.0 for legacy OGC clients
  • Full CRUD transactions

QGIS, OpenLayers, MapLibre, and any OGC-compliant client.

OData v4 + MVT

Enterprise data + vector tiles

  • 21 OData operations ($filter, $select, $orderby, $apply, $batch, $search, $expand, spatial functions)
  • Aggregation, change tracking, batch operations
  • Vector tiles at /tiles/{layer}/{z}/{x}/{y}.mvt

Power BI, Excel, Tableau, SAP, and any OData v4 client. No plugins required.

Deploy in Minutes

Self-serve deployment for evaluation. Docker or Kubernetes.

Docker

docker run -p 8080:8080 \
  -e ConnectionStrings__DefaultConnection="Host=postgres;Database=honua;Username=postgres;Password=postgres" \
  -e HONUA_ADMIN_PASSWORD="change-me" \
  honuaio/honua-server:latest

Kubernetes (Helm)

helm dependency update infrastructure/helm/honua
helm install honua infrastructure/helm/honua \
  --set secret.env.ConnectionStrings__DefaultConnection="Host=postgres;Database=honua;Username=honua;Password=honua" \
  --set secret.env.HONUA_ADMIN_PASSWORD="change-me"
